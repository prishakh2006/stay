🔒 Database Concurrency & Safety

Row-Level Locking: Before inserting, the backend initiates a transaction and executes:

SELECT room_id FROM Room WHERE room_id = ? FOR UPDATE;

This serializes concurrent booking requests so two staff members cannot book the exact same room simultaneously.

⚡ MySQL Trigger Protection

The before_reservation_insert trigger checks if another reservation for this room overlaps the dates:

new.check_in < existing.check_out AND new.check_out > existing.check_in

If an overlap is detected, the database aborts the transaction with error: "Room already booked for these dates".
