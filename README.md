# LuxeStay – Hotel Reservation DBMS

## About the Project
LuxeStay is a hotel reservation management system developed as a Database Management System (DBMS) project.

## Features
- Hotel room reservation management
- Database schema and SQL queries
- Sample data for testing
- Web interface for users

## Technologies Used
- Python
- SQL
- HTML and CSS
- Flask (if used in the project)

## Project Structure
- `app.py` – Application entry point
- `schema.sql` – Database schema
- `queries.sql` – SQL queries
- `sample_data.sql` – Sample database records
- `templates/` – HTML templates
- `static/` – CSS, JavaScript, and images

## How to Run
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run the application using `python app.py`.

## Purpose
This project demonstrates database design and hotel reservation management.
